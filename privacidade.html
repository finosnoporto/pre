Privacidade e cookies

Esta página explica, em linguagem simples, que informações podem ser tratadas quando utilizas o Finos no Porto e como podes exercer os teus direitos.

Quem gere o projeto

O Finos no Porto é um projeto pessoal, não associado a uma empresa ou associação. O responsável pelo tratamento é a pessoa singular que gere o projeto. Para questões de privacidade ou pedidos relativos aos teus dados, contacta finosnoporto@gmail.com.

Estatísticas de utilização

Com o teu consentimento, usamos o Google Analytics 4 para compreender de forma estatística como o site é utilizado, por exemplo, quais as páginas e funcionalidades mais consultadas. A base para este tratamento é o consentimento, que podes retirar a qualquer momento através de «Gerir preferências». Se recusares, o Analytics não é carregado. Se retirares uma aceitação anterior, a preferência é guardada, a etiqueta é removida e a página é recarregada sem iniciar o Analytics.

A escolha é guardada no armazenamento local do navegador (localStorage) para não voltarmos a perguntar em cada página. Esta preferência apenas regista a tua escolha — não ativa o Analytics. Podes limpar os dados do navegador, mas, nesse caso, o aviso poderá voltar a aparecer.

Dados tratados para o funcionamento do site

O site carrega os dados dos bares através da infraestrutura do projeto (Google Apps Script e Google Sheets) e utiliza Leaflet e mapas OpenStreetMap. Estes pedidos técnicos podem revelar aos respetivos fornecedores informações necessárias à comunicação, como o endereço IP, o tipo de navegador e dados do dispositivo. As ligações a serviços externos ficam sujeitas também às políticas desses fornecedores.

Localização do dispositivo

A funcionalidade «Perto de mim» só acede à localização quando a ativas e autorizas o navegador. É utilizada para centrar o mapa e calcular a proximidade no teu dispositivo. O site não envia as coordenadas GPS para a folha de dados do projeto nem as inclui nos eventos personalizados do Google Analytics.

Sugestões e correções enviadas

Se sugerires um bar ou enviares uma correção, os dados que preencheres são enviados para Google Apps Script/Google Sheets para analisar a sugestão, verificar a informação e manter o diretório atualizado. O mapa pode ser utilizado sem criar uma conta. Evita incluir nomes, contactos ou outros dados pessoais que não sejam necessários nos campos livres.

Fundamentos do tratamento

O Google Analytics só é utilizado com base no teu consentimento. A utilização das funcionalidades que pedes (como carregar o mapa ou enviar uma sugestão) envolve o tratamento técnico necessário para prestar essas funcionalidades. As sugestões e correções são também utilizadas para o interesse legítimo do projeto em manter um diretório de preços fiável e reduzir contribuições incorretas ou abusivas.

Conservação

A escolha de consentimento permanece no teu navegador até a alterares ou apagares os dados locais. Os dados enviados nos formulários devem ser conservados apenas durante o tempo necessário para validar a contribuição, manter o diretório fiável e tratar eventuais abusos; dados pessoais desnecessários incluídos nos comentários devem ser eliminados quando identificados. Os dados estatísticos do Google Analytics ficam sujeitos ao período de retenção configurado nas definições da propriedade GA4 e às políticas do Google. O responsável pelo projeto deve confirmar essa configuração antes do lançamento público.

Os teus direitos

Nos termos aplicáveis do RGPD, podes solicitar acesso aos dados pessoais que te digam respeito, a sua retificação ou apagamento, a limitação do tratamento ou opor-te ao tratamento quando aplicável. Quando o tratamento se baseia no consentimento, podes retirá-lo a qualquer momento; isso não afeta o tratamento feito antes da retirada. Para exercer os teus direitos, escreve para finosnoporto@gmail.com. Poderemos pedir informação estritamente necessária para confirmar a identidade antes de responder.

Também podes apresentar uma reclamação à Comissão Nacional de Proteção de Dados (CNPD): informação sobre direitos e como exercê-los.

Serviços de terceiros

O funcionamento do mapa e da API envolve serviços externos, nomeadamente Google Apps Script/Google Sheets, Google Analytics (apenas após consentimento), Leaflet e OpenStreetMap. Estes serviços têm as suas próprias políticas de privacidade e podem tratar dados técnicos nos pedidos que recebem.

Esta informação será revista sempre que forem alterados os serviços, os formulários, as finalidades ou os períodos de conservação.
