Privacidade e cookies

Queremos que possas utilizar o Finos no Porto com informação clara sobre os dados tratados quando visitas o site.

Estatísticas de utilização

Com a tua autorização, usamos o Google Analytics 4 para compreender como o site é utilizado, por exemplo, quais as páginas mais visitadas e quais as funcionalidades mais usadas. O Analytics só é carregado depois de escolheres «Aceitar estatísticas». Se recusares, não carregamos essa ferramenta. A tua escolha fica guardada no armazenamento local do navegador (localStorage), para não voltarmos a perguntar em cada página; esta preferência não ativa o Analytics. Podes alterá-la a qualquer momento através do botão abaixo ou da ligação no menu do mapa.

Mapa, API e serviços externos

Para apresentar os bares e os mapas, o site comunica com serviços externos, incluindo a API do projeto alojada no Google Apps Script/Google Sheets, a biblioteca Leaflet e os mapas OpenStreetMap. Quando o navegador faz pedidos a serviços externos, esses fornecedores podem receber dados técnicos necessários à comunicação, como o endereço IP e informações do navegador, de acordo com os respetivos serviços e políticas.

Localização do dispositivo

A opção «Perto de mim» só utiliza a localização do dispositivo depois de a ativares e de concederes autorização ao navegador. A localização serve para centrar o mapa na tua posição. O site não envia as coordenadas GPS para a folha de dados do projeto nem as inclui nos eventos do Google Analytics.

Informação enviada através dos formulários

Quando sugeres um bar ou envias feedback sobre um preço, os dados que preenches são enviados para a infraestrutura Google Sheets/Apps Script usada pelo projeto para analisar as sugestões e manter a informação dos bares. Não te pedimos uma conta de utilizador para utilizar o mapa. Evita incluir dados pessoais desnecessários nos comentários.

Responsável e contacto

Podes contactar-nos para questões sobre privacidade ou para apresentar um pedido relativo aos teus dados através de finosnoporto@gmail.com. Antes do lançamento público, esta informação deve ser completada com a identificação formal da pessoa ou entidade responsável pelo tratamento e com os prazos de conservação aplicáveis.

Esta página deve ser revista sempre que forem alterados os serviços usados, os formulários ou as práticas de recolha de dados.
